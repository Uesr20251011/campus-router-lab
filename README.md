# 校园路由实验室

课程题目七的 Qt Quick 图形界面原型。界面可编辑网络拓扑，并逐步演示 Prim、Kruskal 最小生成树和最大流。

![最大流最终路径预览](docs/preview.png)

## Windows 双击版

从 GitHub Releases 下载 `CampusRouter-v1.1.0-Windows.zip`，解压后双击其中的 `CampusRouter.exe`，无须安装 Qt 或打开 Qt Creator。程序静默启动，不会弹出控制台。Qt 运行库放在 exe 旁边，因此要保留整个解压文件夹。

源码可在 Qt Creator 中打开 `CMakeLists.txt`，使用 Qt 6.11.2 MinGW 64-bit 套件构建。`package.ps1` 是 Windows 打包脚本；在其他电脑上使用前，需要把脚本开头的 Qt、MinGW 和 CMake 路径调整为本机安装位置。

## 使用

1. 用 Qt Creator 打开本目录的 `CMakeLists.txt`，选择 Qt 6.11.2 MinGW 64-bit 套件，构建并运行 `campus_router`。
2. 右上角“网络管理”可载入校园网络与两个内置例题，也可保存当前网络为本机预设，或输入节点数生成随机网络。预设保存节点名称、位置、链路和权值，重启后仍可载入。左侧可选择拖动、添加节点、连接节点；添加和连接工具会保持选中，方便连续操作。手动切换工具或按 Esc 可退出。随机网络节点数、起点和终点都可直接键入，也可用加减按钮调整。右键节点可就近删除，也可在右侧属性栏删除；按 Delete 可删除选中的节点或链路。
3. 点击节点或链路后，在右侧修改名称、建设造价、最大传输容量和方向。
4. 运行算法后，使用底部时间轴逐步查看。Prim 或 Kruskal 到达最后一步时，可点“只看最小树”：其余边从视图及受力模拟中移除；点“恢复全图”即可继续查看原网络。
   再次点击当前算法按钮可退出演示、清除算法高亮并恢复完整拓扑，保留已编辑的节点和链路；点击其他算法按钮可直接切换。
5. 最大流从初始流量 0 开始。边权 `0/7` 表示“已用流量/总容量”；搜索路径以橙色显示，找到的通路以绿色显示，随后逐条扣减剩余容量。剩余容量为 0 的原向边会变灰，紫色虚线箭头表示可以回退的反向剩余容量。到最后一步时，图上以不同颜色显示所有实际承载流量的路径，右侧列出每条路径及其流量；点击列表中的路径可单独突出显示。
6. 默认拖动节点时，邻近节点会实时受斥力和弹簧力影响；松手后短暂稳定。点击“固定节点模式”后可自由排布，拖动只移动当前节点并保存位置，此时“自动整理”暂不可用。普通点击节点不会启动受力排布。鼠标悬停节点可突出与之相连的边；悬停链路可查看两端节点及两个权值。密集网络默认只显示相关边权，点击“全部边权”可展开。
7. 滚轮缩放，按住鼠标中键平移，点击“适应”回到全图。有向边使用更醒目的蓝色线和箭头，无向边没有箭头。

若 Qt 的 `qmlimportscanner` 在中文路径下无法配置，可用 Windows 的 `subst` 将项目所在目录映射到纯英文盘符，再从该盘符配置 CMake。

## 验证

运行 CTest 中的 `router_tests` 与 `canvas_tests`。例题核对值：图 2 的最小造价为 41，图 3 的最大流为 13。
